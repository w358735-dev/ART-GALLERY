# ART-GALLERY — файлы для скачивания

## Без архива

[Скачать один файл preview.html](preview.html?raw=true)

Сохраните файл на компьютер и откройте его из папки «Загрузки» в браузере. В нём находятся все картины, стили и скрипты; распаковка и сервер не нужны. Если по ссылке показывается код, сохраните его как `preview.html`, без расширения `.txt`, затем откройте сохранённый файл. GitHub показывает исходный код HTML и не запускает сайт на странице репозитория.
